# 声栞 · 设计记录

## 一句话

本地 AI 配音工作台，把小说变成多角色有声剧。核心不是"功能多"，是"改台词不烦、生成只跑改动句、AI 做了什么看得见"。

## 视觉

**概念：录音棚里的稿纸。**

外壳像一台安静的开盘机：石墨黑、铜色刻度、细金属线。中间台词区像一叠真正的剧本稿纸：米白、宋体、行距宽，角色名成列。铜色只用来标「正在这里」，不做装饰。

| 角色 | 色值 | 用法 |
|---|---|---|
| 机壳 | `#0C0E11` | 窗口底色 |
| 面板 | `#16191E` | 侧栏、底栏、卡片 |
| 抬起 | `#1C2027` | 输入框、悬停表面 |
| 边线 | `#252B33` | 只在必要处出现 |
| 稿纸 | `#F2EDE3` | 台词区、原文 |
| 墨色 | `#211E19` | 台词正文 |
| 铜 | `#C0863F` | 强调、播放头、当前句 |
| 亮铜 | `#E0A45D` | 悬停、可点击强调 |
| 青 | `#79A79B` | 已生成、成功 |
| 朱 | `#C25B45` | 失败、删除 |

字体：

- 界面：Noto Sans SC，14px 基准，行高 1.55
- 台词：Noto Serif SC，20px / 行高 1.95
- 标题：Noto Serif SC，页面标题 27–34px
- 时间码、参数：Cascadia Mono / JetBrains Mono

形态：

- 圆角 7–12px，页面级面板 12px，按钮 7–8px，小标签 4–5px。
- **按钮默认没有边框**。优先级用底色、文字色和填充表达：primary 铜色填充，普通按钮淡底，ghost 纯文字。
- 输入框、下拉框、拖放区保留表面色和聚焦铜线，其余容器尽量不用方框。
- 台词行保持直角，稿纸不做成卡片。
- 章节、角色、音色的「当前项」用 2px 铜线 + 极浅暖底，不用整块高亮。

## 布局

```
顶栏 62px
左 244px 章节树（窄窗 222 / 200）
中 弹性 稿纸，最大 840px
右 392px 当前句参数、本章角色、生成状态、AI 工具（窄窗 344 / 306）
底 72px 播放条
```

项目库 42/48px 内边距，卡片最小 276px；角色页左栏 330px，音色卡最小 258px；设置页内容最大 680px。

## 动效

动效只回答「刚才发生了什么」，不做常驻装饰。

- 页面切换：320ms，淡入 + 上移 7px。
- 项目卡和音色卡：入场错峰 0.035s，最多 8 张；悬停上浮 2–3px。
- 当前句：左侧铜线用 `scaleY` 展开，背景是暖色渐变。
- 顶栏导航：下划线 `scaleX` 展开。
- 弹窗：遮罩淡入 180ms，内容 220ms 从 0.985 放大。
- 播放：只有真正播放时 VU 才动；波形不做逐柱无限动画。
- 全部动效遵循 `prefers-reduced-motion`。

## 性能

- 不使用全屏 `backdrop-filter`，弹窗遮罩只用半透明底色。
- 过渡只写 `transform / opacity / background-color`，不写 `transition: all`。
- 原文段落开启 `content-visibility: auto`，离屏内容不参与布局和绘制；台词列表不用它，保证角色跳转落点稳定。
- 旧的 `styles-additions.css` 已并入 `styles.css`，原文件已移到回收站。


## 交互原则

1. **语速只有五档**：很慢、慢、正常、稍慢、快。界面永远不出现"数字越小越快"。
2. **改动句只标黄点**：文本、角色、情绪、语速、音色任一变化，句子进入 dirty。批量生成只跑 dirty。
3. **AI 不是黑盒**：拆分显示 6 个步骤、实时日志、低置信度标记；检查显示具体哪一句、什么问题。
4. **手动参数一直在**：快速模式只隐藏参数，不删除；切回精细模式随时改。
5. **配置说人话**：每项有一句说明和测试按钮，不让人编辑 JSON 或开 bat。

## IndexTTS 2.5 参数

工作台右栏直接对应模型能力：

- 情感控制四种：跟随音色、参考音频、8 维向量、文字描述
- 8 维向量：高兴、愤怒、悲伤、害怕、厌恶、忧郁、惊讶、平静
- `emo_alpha` 强度 0–1
- 语速五档（底层映射到模型时长控制）
- 发音纠正：拼音 / CMU 音素 / 日语假名
- 高级参数放设置：bf16/fp16/fp32、CUDA kernel、DeepSpeed、temperature、top_p、top_k、repetition_penalty、参考音频预处理

## MCP

外部 AI 通过 stdio MCP 操作项目：

- 读项目、读台词
- 改台词、角色、情绪、语速
- 调引擎重拆
- 调 IndexTTS 生成
- 查审计日志

权限分四档：只读 / 可改台词和角色 / 可生成音频 / 完全控制。每次修改写 `mcp/data/audit.jsonl`。

## 为什么不做音谷二开

- 音谷 1.1.6 是 AGPL-3.0，作者另加"未获书面授权不得商用"。
- 前端源码在 `app.asar` 里完整存在，但核心页面 `ProjectDubbingDetail.vue` 单文件 157KB，拆角色、情绪、音色、生成、音频编辑全塞一起。改造成本高于重写。
- 已有的音色库、桥接脚本、拆分代理都在磁盘上，和音谷 UI 解耦，可以原样复用。

结论：保留引擎协议，重写前端。
