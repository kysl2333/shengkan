# 声栞 · 设计记录

> 规范级 token、主题和组件规则见根目录 `DESIGN.md`；本文件记录设计意图和交互原则。

## 一句话

本地 AI 配音工作台，把小说变成多角色有声剧。核心不是"功能多"，是"改台词不烦、生成只跑改动句、AI 做了什么看得见"。

## 视觉

**概念：日间编辑室。**

一张放在工作台上的剧本：纸白、墨色、装订绿的书脊、黄铜的阅读灯。不是深色录音棚的反色版，而是同一间编辑室在白天和夜里。

两套主题：

- **日间（默认）**：纸白工作台、白色文稿、墨色文字，装订绿负责操作，黄铜负责时间。
- **夜间**：深墨绿灰，不是纯黑；绿色提亮，黄铜保持温度，朱砂只标错误和删除。
- 顶栏右侧切换，选择记忆在 `localStorage` 的 `shengkan:theme`；首次进入默认日间。

| 角色 | 日间 | 夜间 | 用法 |
|---|---|---|---|
| 工作台 | `#F4F2EC` | `#111412` | 页面底色 |
| 文稿 | `#FFFFFF` | `#171B17` | 台词纸、面板、卡片 |
| 次级表面 | `#FAF9F5` | `#1F241F` | 输入框、悬停 |
| 边线 | `#E3DFD5` | `#2D342D` | 只作分隔 |
| 墨色 | `#1D211D` | `#E8E9E1` | 正文 |
| 装订绿 | `#2F6B57` | `#93C4AC` | 主操作、当前项、成功 |
| 黄铜 | `#A9763C` | `#D6A268` | 播放头、当前句、时间 |
| 朱砂 | `#B24A35` | `#E08A75` | 失败、删除 |

字体：

- 界面：Noto Sans SC，13.5px 基准，行高 1.6
- 台词：Noto Serif SC，19px / 行高 1.95
- 标题：Noto Serif SC，页面标题 26–32px
- 时间码、参数：Cascadia Mono / JetBrains Mono

形态：

- 圆角 5–10px：文稿和面板 10px，按钮 7px，小标签 4px。
- **按钮默认没有边框**。主操作用装订绿填充，普通按钮用浅绿底，次级操作只用文字色；输入框和拖放区保留边界。
- 项目库不是卡片墙，而是一排书：书封用平涂色块和竖排书名，左侧留书脊，悬停只抬起 2px。
- 文稿是桌面上的纸：左右留出工作台底色，纸面带 1px 边线和很轻的阴影。
- 章节、角色、音色的当前项用 2px 装订绿或黄铜线 + 极浅底色，不用整块高亮。
- 不使用渐变、发光和全屏毛玻璃。

## 布局

```
顶栏 60px
推荐流程条 32px
左 232px 章节树（窄窗 212 / 196）
中 弹性 文稿，最大 860px
右 372px 当前句参数、本章角色、生成状态（窄窗 340 / 300）
底 66px 播放条
```

项目库 38/48px 内边距，书封高 172px；角色页左栏 320px，音色卡最小 250px；设置页内容最大 680px。文稿在工作台中央，不再铺满整块中间区域。

**工作台的 AI 入口只在顶部工具栏。**「AI分析」按钮打开二级菜单，集中 AI 重拆本章、AI 标注角色、规则重拆；右栏只在分析进行时显示进度和日志。顶部流程条写明：AI分析角色 → 补齐角色/指派未知台词 → 绑定音色 → 生成配音 → 成片导出。不要把 AI 工具重新埋回右栏底部。

## 动效

动效只回答「刚才发生了什么」，不做常驻装饰。

- 页面切换：240ms，淡入 + 上移 4px。
- 项目卡和音色卡：入场错峰 0.025s；悬停上浮 2px。
- 当前句：左侧黄铜线用 `scaleY` 展开，底色变暖。
- 顶栏导航：下划线 `scaleX` 展开。
- 弹窗：遮罩淡入 160ms，内容 180ms 上移 6px。
- 播放：只有真正播放时 VU 才动；波形不做逐柱无限动画。
- 主题切换即时生效，不做大面积颜色过渡。
- 全部动效遵循 `prefers-reduced-motion`。

## 性能

- 不使用全屏 `backdrop-filter`，弹窗遮罩只用半透明底色。
- 过渡只写 `transform / opacity / background-color / border-color`，不写 `transition: all`。
- 进度条不靠动画 `width`，避免触发布局。
- 原文段落开启 `content-visibility: auto`，离屏内容不参与布局和绘制；台词列表不用它，保证角色跳转落点稳定。
- 旧的 `styles-additions.css` 已并入 `styles.css`，原文件已移到回收站。


## 交互原则

1. **语速只有五档**：很慢、慢、正常、稍慢、快。界面永远不出现"数字越小越快"。
2. **改动句只标黄点**：文本、角色、情绪、语速、音色任一变化，句子进入 dirty。批量生成只跑 dirty。
3. **AI 不是黑盒**：拆分显示 6 个步骤、实时日志、低置信度标记；检查显示具体哪一句、什么问题。
4. **手动参数一直在**：快速模式只隐藏参数，不删除；切回精细模式随时改。
5. **配置说人话**：每项有一句说明和测试按钮，不让人编辑 JSON 或开 bat。

## IndexTTS 2.5 参数

工作台右栏直接对应模型能力：

- 情感控制四种：跟随音色、参考音频、8 维向量、文字描述
- 8 维向量：高兴、愤怒、悲伤、害怕、厌恶、忧郁、惊讶、平静
- `emo_alpha` 强度 0–1
- 语速五档（底层映射到模型时长控制）
- 发音纠正：拼音 / CMU 音素 / 日语假名
- 高级参数放设置：bf16/fp16/fp32、CUDA kernel、DeepSpeed、temperature、top_p、top_k、repetition_penalty、参考音频预处理

## MCP

外部 AI 通过 stdio MCP 操作项目：

- 读项目、读台词
- 改台词、角色、情绪、语速
- 调引擎重拆
- 调 IndexTTS 生成
- 查审计日志

权限分四档：只读 / 可改台词和角色 / 可生成音频 / 完全控制。每次修改写 `mcp/data/audit.jsonl`。

## 为什么不做音谷二开

- 音谷 1.1.6 是 AGPL-3.0，作者另加"未获书面授权不得商用"。
- 前端源码在 `app.asar` 里完整存在，但核心页面 `ProjectDubbingDetail.vue` 单文件 157KB，拆角色、情绪、音色、生成、音频编辑全塞一起。改造成本高于重写。
- 已有的音色库、桥接脚本、拆分代理都在磁盘上，和音谷 UI 解耦，可以原样复用。

结论：保留引擎协议，重写前端。
