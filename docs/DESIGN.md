# 声栞 · 设计记录

## 一句话

本地 AI 配音工作台，把小说变成多角色有声剧。核心不是"功能多"，是"改台词不烦、生成只跑改动句、AI 做了什么看得见"。

## 视觉

**概念：录音棚里的稿纸。**

外壳像一台老式开盘机：深炭灰、铜色刻度、VU 表。中间台词区像一叠剧本稿纸：米白、宋体、角色名成列。

| 角色 | 色值 | 用法 |
|---|---|---|
| 机身 | `#0F1114` | 窗口底色 |
| 面板 | `#16191E` | 侧栏、底栏 |
| 边线 | `#242A31` | 分隔、输入框 |
| 稿纸 | `#EFEAE0` | 台词区 |
| 墨色 | `#23201B` | 台词正文 |
| 铜 | `#C08A4E` | 强调、播放头、当前句 |
| 青 | `#6E9E96` | 已生成、成功 |
| 朱 | `#C4553F` | 失败、待处理 |

字体：

- 界面：思源黑体 / Noto Sans SC
- 台词：思源宋体 / Noto Serif SC，17px / 行高 1.9
- 时间码、参数：JetBrains Mono

圆角统一 6–10px。台词行保持直角，稿纸不做成卡片。

## 布局

```
顶栏 54px
左 236px 章节树 + 角色速览
中 弹性 台词稿 / 原文 / 播放条
右 328px AI 任务 + 角色 + 当前句参数
底 74px 播放条
```

当前句用 2px 铜线 + 极浅暖底，不用整块高亮。情绪和语速是角色名下面的小标签，不抢视线。

## 交互原则

1. **语速只有五档**：很慢、慢、正常、稍慢、快。界面永远不出现"数字越小越快"。
2. **改动句只标黄点**：文本、角色、情绪、语速、音色任一变化，句子进入 dirty。批量生成只跑 dirty。
3. **AI 不是黑盒**：拆分显示 6 个步骤、实时日志、低置信度标记；检查显示具体哪一句、什么问题。
4. **手动参数一直在**：快速模式只隐藏参数，不删除；切回精细模式随时改。
5. **配置说人话**：每项有一句说明和测试按钮，不让人编辑 JSON 或开 bat。

## IndexTTS 2.5 参数

工作台右栏直接对应模型能力：

- 情感控制四种：跟随音色、参考音频、8 维向量、文字描述
- 8 维向量：高兴、愤怒、悲伤、害怕、厌恶、忧郁、惊讶、平静
- `emo_alpha` 强度 0–1
- 语速五档（底层映射到模型时长控制）
- 发音纠正：拼音 / CMU 音素 / 日语假名
- 高级参数放设置：bf16/fp16/fp32、CUDA kernel、DeepSpeed、temperature、top_p、top_k、repetition_penalty、参考音频预处理

## MCP

外部 AI 通过 stdio MCP 操作项目：

- 读项目、读台词
- 改台词、角色、情绪、语速
- 调引擎重拆
- 调 IndexTTS 生成
- 查审计日志

权限分四档：只读 / 可改台词和角色 / 可生成音频 / 完全控制。每次修改写 `mcp/data/audit.jsonl`。

## 为什么不做音谷二开

- 音谷 1.1.6 是 AGPL-3.0，作者另加"未获书面授权不得商用"。
- 前端源码在 `app.asar` 里完整存在，但核心页面 `ProjectDubbingDetail.vue` 单文件 157KB，拆角色、情绪、音色、生成、音频编辑全塞一起。改造成本高于重写。
- 已有的音色库、桥接脚本、拆分代理都在磁盘上，和音谷 UI 解耦，可以原样复用。

结论：保留引擎协议，重写前端。
