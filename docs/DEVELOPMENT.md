# 开发与构建说明

面向开发者和贡献者。用户安装、功能和使用说明看根目录 [README.md](../README.md)。

## 目录

```
声栞/
├─ design/preview.html   旧版静态视觉稿（仅历史参考）
├─ DESIGN.md             规范级设计 token、主题和组件规则
├─ app/                  Electron + React 桌面应用
│  ├─ src/               页面、组件、导入解析、AI 桥接
│  └─ electron/          主进程、项目读写、引擎管理、AI 调用、日志
├─ engine/               IndexTTS 本地引擎 + 远端 Gradio 代理
├─ mcp/                  MCP 服务器
├─ projects/             项目文件夹
├─ voices/               参考音频 + meta.json
├─ docs/                 设计决策、开发日志、交接档案
├─ AGENTS.md             长期约定，AI 和接手的人先读
├─ CHANGELOG.md          改动记录
├─ start.bat             启动入口
└─ README.md             本文件
```

## 界面

默认是日间主题：纸白工作台、白色文稿、装订绿操作、黄铜播放头。整体缩放为 0.9；顶栏右侧可以切到夜间，选择会记住。窄中栏会将角色名放在正文上方，播放器空间不足时分两行，长角色名、英文和网址自动换行。设计 token 和主题规则见 `DESIGN.md`。

## 启动

双击 `start.bat`。它会检查依赖、按需构建前端，然后启动 Electron。

开发模式：

```powershell
cd app
npm.cmd run dev
# 另一个终端
$env:SHENGKAN_DEV_URL="http://127.0.0.1:5173"
npx.cmd electron .
```

工作台状态回归检查：

```powershell
cd app
npm.cmd run check:studio
```

构建 Windows 安装包：

```powershell
cd app
npm.cmd run dist
```

输出在 `release/shengkan-<version>-setup.exe`。安装包未做代码签名，Windows SmartScreen 可能提示「未知发布者」。

## 已实现

### 导入

- 拖拽或选择 `.txt / .md / .epub / .docx`
- EPUB 按目录锚点分章，DOCX 按段落提取正文，过滤版权页、目录、制作信息
- TXT 自动识别 UTF-8 / UTF-16 / GBK
- 导入前预览章节、字数、预计句数
- 「合并 800 字以下短章」

### AI

- 文本 AI 和 TTS AI 分开配置：文本负责分章、角色、情绪和语速；TTS 负责声音，两者可以用不同服务商和 Key
- 文本模型只显示文本模型，TTS 模型只显示 TTS 模型；接口不区分时显示全部
- 设置页可以「获取模型」从云端拉列表；只请求模型列表，不消耗生成次数
- AI 分章：可选小米 MiMo / 千问百炼 / DeepSeek / 自定义，只识别章节，不分析角色
- 分章会优先用 EPUB 目录，禁止把纯数字、页码、小节标题当章节
- AI 角色分析会带书名和章节名；已出版作品可结合 AI 已知角色名，不确定保留未知
- 整本角色标注先做整本角色预分析，避免角色全名后出现时漏识别
- AI 角色提取：过滤作者、插画、制作信息等非人物，支持中/英/日说话标记
- AI 重拆本章：规则拆句 → AI 分析角色 → 标注角色、情绪、语速
- 角色标注更通用：引号里的名字不等于说话人；电话、对讲机、广播、录音里的声音没有明确说话人时标「未知」；叙述中夹带的术语/书名/招牌改成「旁白」
- 整本编辑在项目库右键：「整本重拆章节」只拆章节不动角色；「整本角色标注 + 情绪 + 语速」逐章处理
- AI 操作结束显示输入/输出/缓存/总计 token
- AI 标注默认整章一次发给模型，开启 MiMo 深度思考；超过 220 句或 6 万字符才分段，段间带前后句上下文
- 分析时右栏实时显示「思考过程」，只展示 reasoning，不显示最终 JSON；设置页可以关闭思考换速度
- 整章思考最长等待 30 分钟；超时或失败会保留错误和已收到的思考，不会直接消失
- 自定义文本 AI 可以勾选「思考强度」低/中/高；不勾选不发送，使用模型默认
- 标注可停止，停止后保留已完成段的结果；AI 重拆取消角色分析后不会再启动下一阶段标注，收尾后可重新载入项目
- 提示词可在设置页查看、编辑、恢复内置

### 语音引擎

- 优先用 TTS 地址 / Gradio API：本地 WebUI 填 `http://127.0.0.1:7860`，远端填局域网地址；不用 Python
- 本机 Python 模式需要 IndexTTS 代码和权重，收在「高级」里；只有完全自动化时再用
- 顶栏引擎状态会区分「引擎在线」和「IndexTTS 2.5 已加载」，远端不可达时不会显示已加载
- 同时进行的健康检查共享一次请求，最多等待 10 秒且不缓存结果；桌面工作台 TTS 请求上限为 4 分钟，普通查询和导出为 2 分钟
- 引擎错误显示 Node `error` 或 Python `detail` 的具体原因；连接与生成失败提示使用朱砂色

### 工作台

- 顶栏「AI分析」是二级菜单：AI 重拆本章、AI 标注角色、规则重拆
- 工作台顶部有推荐流程：AI分析角色 → 补齐角色、指派未知台词 → 绑定音色 → 生成配音 → 成片导出
- 「生成」按钮叫「生成配音」
- 台词双击编辑，回车保存，自动标 dirty
- 勾选生成、单句生成、整章生成、批量生成；云 TTS 支持多句并发
- 生成前可选「未生成/全部」；生成中可取消
- 生成时文稿上方显示当前句、角色、实际引擎和完成数；右栏「本次生成」也显示实际引擎
- 云端失败会自动重试：串行 + 间隔，结束显示重试成功和仍失败数量
- 换角色、新建角色、插入台词、删除台词
- 章节新建、重命名、删除、编辑原文、单章生成
- 试听支持单句 / 连续，播放条可拖动，倍速 0.5-3.0
- 连续试听跳过没有音频的句子，自动跟随当前句滚动并闪烁；倍速在整段试听中保持
- 连续试听和换句播放复用同一个音频元素，切换到下一句不会被暂停
- 连续试听途中改为单句播放后，本句结束即停止；底部播放器的暂停/继续仍保留连续队列
- 播放器波形铺满整条，点击或拖动任意位置都能跳转
- 波形用圆角竖条、悬停高亮和播放头指示；倍速快速切换不会卡顿
- 点击 ⇄ 切换上一版配音会 toast 提示、闪烁当前行并自动播放
- 语速用 0.5-2.0 数字滑块/输入，云 TTS 和本地 IndexTTS 都生效
- 本章角色可用上下箭头和数字直接跳到该角色的第 N 句
- 台词显示原文段号；句中短引号不会被误拆成台词
- 跨段续句会合回上一段旁白，例如段落末尾没有句号、下一段以「“blessing software” 的成员。」开头；另起一句时会补一个「，」当停顿
- 规则重拆和整本重拆只换断句；文字完全相同的旧台词保留角色、情绪、语速和音频
- 选中台词后切「原文」会定位到对应段并短暂高亮

### 角色和音色

- 角色来自项目 `casts`，跨章节共享
- 新建、重命名、右键删除、清理无效角色
- 音色绑定、播放/暂停
- 音色显示名和描述来自 `voices/meta.json`
- 云音色：小米 MiMo、千问 TTS（DashScope）、自定义 OpenAI 兼容 `/audio/speech`
- 加入本地音色库：把云样本放进本地音色库，再绑定到角色走 IndexTTS
- 没有名字的路人可以用「OL女性」「店员」这类身份名
- AI 设计音色：先生成试听，满意再保存；保存后进入云音色，点「加入本地音色库」才进本地音色
- 云音色和本地音色都可以删除，文件移到 `voices/.trash`；预置云音色不能删除或改名
- 角色页管理整个项目的角色；工作台右侧只管理本章角色
- 音色按钮只作用于左侧当前选中的角色：云/本地都叫「绑定到角色」，再点取消绑定
- 「加入本地音色库」只复制样本，不绑角色；到本地音色卡再绑定
- 音色历史：每个角色能看到用过的音色，可单条移除
- 音色名称和介绍在同一个编辑弹窗里修改
- 每句台词最多保留 2 个音频，可切换回退；生成失败保留旧音频
- 音色库按分类分组；默认窗口缩放 0.9，兼顾阅读和工作区空间

### 项目

- 项目右键：打开、重命名、移到回收站
- 软件与 MCP 同时修改项目时会检测写入冲突：暂停保存并保留当前草稿，可先「下载草稿副本」，再确认「重新载入最新项目」；不自动合并或覆盖外部修改
- 保存失败还会自动写入项目根目录 `.recovery/` 并显示文件位置，草稿保留新音频引用；遇遗留锁可点「恢复已退出进程的锁」，仍存活或无法确认来源的锁不会被强行清除
- 回收站：还原、彻底删除、清空回收站，与保存共享源/目标锁；彻底删除会一并清理项目音频。遇到 `PROJECT_BUSY` 时可点该项目的「恢复遗留锁」，仅处理确认已退出的进程
- 删除台词/章节、重新拆分或淘汰历史版本时，项目保存成功后才清理被替换的旧音频；保存失败保留旧引用
- 成片页可按章节导出整轨 WAV、SRT 和分轨 ZIP
- 成片时间轴每行一个角色，横向按全章台词顺序估算时间；悬停色块可看句号、起止时间和台词片段
- 支持整本单轨导出、整本分章节 ZIP；导出历史保存在本机
- 导出结果可以一键在资源管理器中打开

## 已知限制

- 首次使用时项目库和音色库都是空的；需要自己导入小说并准备参考音频，不附带示例文章或示例项目
- 音色库为空时生成会提示先绑定音色
- 整本角色标注会调用很多次 AI，耗时长、消耗 token；结束会显示 token 统计
- 语速范围 0.5-2.0；云 TTS 和本地 IndexTTS 都支持
- 模型列表依赖服务商的 `/models` 接口；不提供或分不清 TTS/文本时会显示全部，仍可手动填写
- MCP 权限由启动环境变量 `SHENGKAN_MCP_PERMISSION` 控制，默认 `generate`
- 开发日志超过 5 MB 自动轮转，只保留 1 份备份；设置页可以手动清空
- 旧项目里有重复角色 id 的，加载时会自动去重；如果两个角色已经被绑定到同一个音色，需要在角色页手动解绑其中一个
- 旧项目的错误角色需要「清理无效角色」或整本角色标注
- `release/` 里的安装包是构建产物，改了代码要重新 `npm run dist`；当前 v1.0.1 已发布
- 应用图标已接入 `app/build/icon.ico`；换 logo 后要重新生成 `.ico` 再打包
