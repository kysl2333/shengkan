# 窄稿台词阅读与长文本适配

Status: ready-for-agent

## 问题与方案

连续英文或网址按最小内容宽度撑出稿纸；中栏较窄时固定角色列挤压正文。保留三栏与播放行为，正文列允许收缩及长词换行；中栏不超过 540 CSS px 时，勾选保留左侧、角色名置于正文上方。

## 约束

- 沿用现有字号、1.95 行高、语义颜色、纸面与侧栏宽度。
- 宽中栏保持角色名与正文并排；长角色名可换行，不截断数据。
- 不改变项目数据、音频、生成、配置、权限或依赖。
- 所有台词操作、角色菜单、编辑与勾选保持可用。

## 验收

- 1280/1600 窗口、1.0/1.6 缩放、日间/夜间下，长网址不产生稿纸横向溢出。
- 窄稿正文使用可用内容区至少 80% 宽度，位于角色名下方。
- 角色菜单在窄稿内，换角色不丢勾选，编辑不溢出且保存正确，行内操作保留。
- 构建、工作台回归、离线播放和上一轮 UI 回归通过；独立双轴审查。
- 测试脚本仅系统临时目录；不新建测试报告。

## 范围外

跨进程文件锁、整体三栏重设计、顶栏、播放器新功能和真实 TTS 性能。
