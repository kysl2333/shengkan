# 项目恢复与生命周期保护

Status: resolved

## 目标

补齐已记录的遗留锁恢复、保存失败后新音频的可追溯引用，以及回收站操作与保存的并发保护。默认缩放保持 0.9。

## 决策与验收

- 锁记录 PID、随机标识与创建时间；活进程、权限不明或旧格式锁一律不抢占。提供显式恢复入口，只处理可确认持有者已退出的锁；保留恢复证据，不删除用户项目或音频。
- 保存前后再次校验磁盘摘要，尽可能检测不遵守锁的外部修改；不承诺能约束任意外部编辑器在最后瞬间的写入。
- 保存、移入回收站、还原及彻底删除使用相同的跨进程协调规则；锁位于不会随项目目录移动而失效的位置。回收站失败不清理音频。
- Electron/MCP 保存失败自动写唯一恢复草稿文件，剥离传输元信息并保留新音频引用，返回恢复文件位置；成功项目 JSON 格式不变。不自动清理真实未引用音频。
- 界面显示恢复草稿保存位置、失败反馈和遗留锁恢复入口；先下载/保留草稿再重新载入。
- 临时夹具验证死锁恢复、活锁拒绝、多进程竞争、回收站生命周期锁、恢复草稿引用和正常保存；构建、工作台、MCP、打包及双轴审查通过。

## 范围外

实际用户数据清理、任意外部编辑器的强制互斥、分布式锁、自动内容合并和新产品功能。完成后合并 main，不自行扩大任务。
