# 声栞 · Shiori Voices

本地 AI 配音工作台。把小说、剧本或同人文本拆成多角色台词，为每个角色匹配音色和情绪，逐句生成音频，最后合成整章有声书。

声栞把「拆章、拆台词、认角色、配音、导出」放在一个桌面应用里。原文和项目保存在本机，只有你主动调用 AI 时，相关文本或音频才会发送给你配置的服务商。

[下载最新安装包](../../releases/latest) · [从源码运行](docs/DEVELOPMENT.md) · [MCP 接入](mcp/README.md)

## 功能

### 导入与拆章

- 支持 `.txt`、`.md`、`.epub`、`.docx`
- TXT 自动识别 UTF-8 / UTF-16 / GBK
- EPUB 按书内目录锚点分章，不按文件硬切
- 规则分章识别「第 X 章 / 回 / 节 / 卷」、序章、楔子、番外、Chapter N 等
- 规则认不出时，可让文本 AI 识别章节；导入前可预览章数和字数

### 台词与角色

- 规则拆句，保证原文一字不改
- 说话人、情绪、语速由文本 AI 标注，可逐句手动修改
- 角色跨章节共享；工作台只显示本章角色
- 支持「未知」说话人、旁白和「店员」「OL 女性」这类身份名
- 引号里的名字不会被误判成说话人；电话、广播、录音里的声音会谨慎处理
- 支持单章 AI 重拆、整本重拆章节、整本角色标注

### 音色与生成

- 本地音色库：导入参考音频，按角色绑定
- 本地 IndexTTS 2.0 / 2.5：通过 Gradio WebUI 或本机 Python 推理
- 云端 TTS：小米 MiMo、千问 TTS（DashScope）、自定义 OpenAI 兼容 `/audio/speech`
- AI 设计音色：先生成试听，满意再保存
- 云音色可以「加入本地音色库」，之后走本地 IndexTTS
- 单句、勾选、整章、整本生成；云 TTS 支持有限并发，失败自动串行重试
- 生成失败保留旧音频；每句最多保留两个版本，可随时回退
- 语速 0.5–2.0，云 TTS 和本地 IndexTTS 都生效

### 试听与成片

- 单句 / 连续试听，自动跟随当前句，可关闭跟随
- 播放器支持拖动进度、0.5–3.0 倍速、暂停后继续
- 按章节导出整轨 WAV、SRT 字幕和分轨 ZIP
- 整本单轨导出、整本分章节 ZIP
- 成片时间轴按全章台词顺序排列，每个角色一条轨道

### 其他

- 日间 / 夜间主题
- 项目回收站、保存冲突检测、恢复草稿
- 可选 MCP 服务器，让外部 AI 读写项目
- 开发日志本机保存，5 MB 自动轮转

## 快速开始

1. **安装并启动**：从 [Releases](../../releases/latest) 下载 `shengkan-*-setup.exe`，按提示安装。
2. **配置文本 AI**：打开「设置 → AI 服务 → 文本 AI」，选择小米 MiMo、千问百炼、DeepSeek 或自定义 OpenAI 兼容服务，填入 Base URL、模型和 API Key，点「测试」确认连接，再点「保存 AI 配置」。
3. **配置配音方式**：
   - 有本地 IndexTTS WebUI：在「语音引擎」里填 `http://127.0.0.1:7860`，保存后重启。
   - 用云 TTS：在「AI 服务 → TTS AI」里启用小米 MiMo、千问 TTS 或自定义 TTS，填入对应的 Key。
4. **导入小说**：回到「项目」，拖入 `.txt / .md / .epub / .docx`，确认章节后创建项目。
5. **准备角色和音色**：在工作台或「角色与音色」里确认角色，给角色绑定本地参考音频或云音色。
6. **生成与导出**：逐句、勾选或整章生成配音；到「成片」导出 WAV、SRT 或分轨 ZIP。

> 第一次使用时项目库和音色库都是空的，不附带示例文章、示例项目或参考音频。你需要自己导入文本并准备音色。

## 文本 AI 与 TTS AI

声栞把两类 AI 分开配置：

| 类型 | 负责 | 常见服务商 |
|---|---|---|
| 文本 AI | 分章、角色分析、情绪和语速标注 | 小米 MiMo、千问百炼、DeepSeek、自定义 OpenAI 兼容 |
| TTS AI | 把台词变成声音 | 小米 MiMo TTS、千问 TTS、自定义 OpenAI 兼容 TTS |

两者可以用不同服务商和不同 Key。文本 AI 的分章和标注提示词可以在设置页查看、编辑和恢复内置；首次安装会显示完整默认提示词。

## 本地引擎

本地配音不捆绑模型权重，需要先准备 IndexTTS 运行环境：

- 推荐让 IndexTTS 以 WebUI / Gradio 方式运行，然后在声栞里填服务地址，例如 `http://127.0.0.1:7860`
- 本机 Python 模式适合完全自动化，需要填写 Python、IndexTTS 代码目录和模型目录
- IndexTTS 2.0 兼容旧权重；2.5 支持语言、时长系数和情感向量
- 没有参考音频时，本地音色库为空，生成会提示先绑定音色

如果你不想部署本地模型，可以直接使用云 TTS。

## 数据与隐私

安装版的数据位置：

| 数据 | 位置 |
|---|---|
| 项目 | `文档/shengkan-projects` |
| 参考音频 | `文档/shengkan-voices` |
| 生成音频 | `%APPDATA%/shengkan/outputs` |
| AI 配置和 Key | `%APPDATA%/shengkan/ai.json` |
| 引擎配置 | `%APPDATA%/shengkan/engine.json` |
| 日志 | `%APPDATA%/shengkan/logs` |

- API Key 只保存在本机 `ai.json`，不会写进项目、日志或安装包。
- 项目、音色和生成音频不会上传到声栞的服务器；本项目没有账号系统和遥测。
- 使用 AI 分章、角色标注或云 TTS 时，相关文本或音频会发送给你配置的服务商，受对应服务商的隐私政策约束。
- 设置页会显示 AI 配置文件的路径，Key 在界面上始终打码。
- 删除项目默认进入回收站；彻底删除只在回收站里执行。

## 系统要求

- Windows 10 / 11 x64
- 本地 IndexTTS：需要单独的 Python 环境和模型权重，建议使用 NVIDIA GPU
- 云 TTS：需要对应服务商的 API Key 和网络连接
- 安装包目前未做代码签名，Windows SmartScreen 可能提示「未知发布者」；确认来源后可选择仍要运行

## 从源码运行

```powershell
git clone <仓库地址>
cd 声栞
start.bat
```

`start.bat` 会在依赖缺失时安装依赖，在需要时构建前端，然后启动 Electron。

开发模式、构建安装包、目录结构和接口说明见 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)。

## 常见问题

**生成时提示「音色库是空的」？**

先准备参考音频并放到音色库，或在「角色与音色」里给角色绑定云音色。安装版默认音色库是空的。

**本地引擎连不上？**

确认 IndexTTS WebUI 已经启动，地址和端口正确；如果 WebUI 关闭，声栞仍可以导入和拆章，但生成会失败。

**AI 分章结果不对？**

EPUB 优先使用书内目录；TXT 可以先用规则分章，再对单章使用「AI 重拆本章」。分章提示词可以在设置页调整。

**模型列表是空的？**

部分服务商不提供 `/models` 接口，或接口不区分文本 / TTS 模型。可以直接手动填写模型名。

**安装后项目库是空的？**

这是正常的。声栞不附带示例项目，第一次使用需要自己导入文本。
